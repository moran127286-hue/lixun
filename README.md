# 力训 · 计划打卡

周期力量训练计划的打卡工具。导入 Excel 计划后，每天点进去即可看当天训练、打勾记录、组间歇自动计时。

## 使用

打开 https://moran127286-hue.github.io/lixun/ ，手机 Chrome 菜单里选择「添加到主屏幕」即可像 App 一样使用。

- 点「📥 导入 Excel」上传周期计划表（.xlsx）
- 支持 1RM × 百分比 自动换算成实际杠铃重量与每侧杠铃片
- 打卡进度保存在本地浏览器，不需要服务器、不上传任何数据

## 技术

单文件前端应用，内联 SheetJS 解析 xlsx，Service Worker 支持离线，PWA 可安装。
